# CoinSphere 使用手册

CoinSphere 以工作流为核心，插件提供具体业务。普通用户可按角色能力及资源授权创建、发布、运行或审批；超级管理员维护系统与能力授权。部署与恢复见[发布手册](runbooks/release.md)和[数据库迁移手册](runbooks/database-migrations.md)。

## 安装与首次登录

使用 PostgreSQL 16 与内置 Vue 的 Go App。新数据库由一次性 migrate 容器建立基线，再启动 backend。旧系统升级不能直接使用新镜像指向旧库，先按迁移手册完成独立目标导入。

Compose 环境需要 Docker Compose v2 和长期保存的随机 `COINSPHERE_AUTH__SECRET_KEY`；新安装可由管理员执行 `docker compose up -d --build`，浏览器打开 http://localhost:8080。初始账号 coinsphere / coinsphere，首次登录立即改密码。生产数据库、交易密钥及服务器配置不要上传到聊天或仓库。

系统不开放公开注册。退出登录会持久撤销当前令牌。密钥签名配置更换会影响登录及保存凭据，必须随恢复点管理。

## 工作台与授权

工作台展示你有权读取的工作流、待办和共享结果。菜单只导航，管理员在角色管理分配独立能力，并在工作流授权配置对应用户/角色资源范围。拥有工作流并不自动拥有全部角色能力；授予人不能授出自己没有的权限。

工作流作者需要 read/create/update，发布、运行、启停、分享与凭据管理分别授权。审批人员需要 human_tasks.read/decide 及对应工作流范围。结果用户需要 result_views.read、插件读取能力及该视图授权；若允许操作还需相应动作能力。

系统观察需要 system.observe，模型配置需要 config.ai.manage，助手需要 assistant.use。助手只能在当前授权范围查询和创建 inactive 草稿，不能自动发布/激活或执行交易。

## 创建、保存、发布与运行

1. 在“工作流定义”选择创建，填写名称和描述，选择模板或直接编辑图；节点库来自当前加载插件。
2. 编辑器分开显示配置、输入绑定、凭据。Config 放静态值；动态输入选择入口输入、固定 JSON 值、节点输出或表达式。金额使用带双引号的十进制字符串。
3. 管理 main 与其他入口，保留事件的完整 types；Loop 打开循环子图。表达式显式使用 `nodes["节点ID"].字段` 和 `input.字段`，不会自动合并节点同名输出。
4. 保存生成新草稿修订，元数据与凭据一起提交，现有发布修订不变化。多人编辑冲突时刷新并重新应用修改。
5. 发布草稿会验证图、owner 执行能力与必需凭据。自动触发执行发布修订；手工运行选择修订、入口和 JSON 输入，可试运行未发布草稿。
6. 需要自动运行时再激活。停用停止自动触发，保留待处理记录；取消某次运行使用运行详情操作。

凭据仅显示已配置/未配置。输入新值表示替换，留空保留，移除明确删除。只有获凭据管理能力才能操作；凭据不会出现在图、输出或共享结果。

历史修订只读。发布新修订使用新的持久状态空间；有状态的工作流串行执行，不跨分区并发覆盖。

## 运行详情与待办

列表摘要显示最近真实状态，waiting 为“等待处理”，retrying 为“等待重试”。详情固定本次 Run，显示执行轨迹、节点尝试、日志、制品、输入和结果；插件 RunPanel 提供业务观察，组件缺失时显示明确提示。

审批在工作台确认通过/拒绝后从待办移除，原运行继续。每个任务只能决定一次；过期、被同业务键新任务替代或取消不能再次批准。

永久配置/输入错误需要修正；临时错误仅按节点安全重试策略继续。unknown_result 表示外部结果未知，重试按钮保持禁用，先由业务人员核对。诊断重放复用原副作用检查点，缺检查点失败，不能用于重新发送通知或下单。

## 共享结果与插件

结果中心按插件目录选择页面、固定范围、过滤与允许动作，再授权用户/角色。访问用户只看到获授权 active 视图，URL/查询参数不能扩大范围。管理者可暂停开放或撤销；撤销永久，不可重新打开，需创建新视图。

插件管理分别展示已安装、已编译、已加载和原因；版本不匹配、缺依赖或未编译要由管理员处理。当前定义、在途运行和未撤销视图引用阻止不安全升级/卸载。可信插件的安装构建操作见[插件指南](plugin-development.md)。

Quant 回测和 Binance 行情/Paper 页面属于插件；站内通知是简单收件箱，审批在工作台。Live 默认关闭，任一风控上限或手工放行缺失都会拒绝执行；此手册不授权真实交易。

## 备份与故障

备份须包含配对数据库、镜像、配置/加密 key 和独占上传/制品。升级失败保持服务关闭，按[迁移恢复流程](runbooks/database-migrations.md)处理；不要执行 Down、删除事实或伪造版本。普通无权访问可能返回 403 或不可发现的 404，联系授权管理者检查能力与资源范围。
