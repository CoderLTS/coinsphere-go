# 质量门禁

门禁按变更路径和风险分层执行。PR 获取快速反馈，开发波次集中验证跨模块行为，`main`、定时和发布承担完整供应链检查；同一检查不在子步骤间重复运行。

## PR 快速层

- Ready PR 必须以 `main` 为 base；Draft stacked PR 可以指向父分支。
- Secret scan 始终运行，只检查受影响模块的格式、Lint、类型、构建和核心测试。
- 涉及 migration、并发事务、金融状态或外部契约时，运行对应 PostgreSQL/TimescaleDB 和契约检查。
- 前端关键交互增加 Chromium 冒烟；依赖清单或锁文件变化时运行对应依赖扫描。
- 文档与治理 PR 只运行文档链接、格式、术语一致性和仓库差异检查，不运行无关业务测试。

## 波次完整层

同一波次的独立切片在临时集成分支组合后只运行一次：

- Go 全量测试、必要 Race 和进程生命周期契约。
- PostgreSQL/TimescaleDB Compose、migration、恢复与跨模块集成。
- Chromium、Firefox、WebKit 关键路径；失败时保留截图、trace 和报告。
- Backend、Frontend、Worker 镜像、Compose 健康和端到端冒烟。
- 安全、交易、权限、凭据、风控或订单状态变更对应的专项契约。

## main 与发布层

- `main`、定时或发布运行完整依赖、文件系统、镜像和供应链扫描，以及跨模块回归。
- 发布归档、Manifest、SPDX SBOM 和 `SHA256SUMS` 必须通过精确清单、校验和、镜像 digest、危险路径及敏感内容检查。
- 生产只能由用户从最新 `main` 手工触发；禁止自动合并、自动真实交易或绕过风控。

## 稳定契约

- 生命周期：同一个根 Context 取消 HTTP、Runtime、数据库和 WebSocket；应用在 30 秒内收尾，Compose 给予 40 秒宽限。
- Worker：任务取消从请求提交到终态不超过 5 秒；旧租约不能续租或提交终态，孤儿任务可恢复。
- 通知：数据库记录是事实源，`pg_notify` 只作唤醒；慢连接不阻塞生产者，离线用户通过未读快照恢复。
- 数据库：认领、续租、恢复和终态写入必须使用数据库时间、租约与 fencing；生产回滚不自动执行 Down。
- 浏览器：支持范围以 `frontend/package.json` 的 `browserslist` 为准；Playwright WebKit 不替代 Safari/iOS 真机验收。

## 领域验收口径

- 行情完整率按每条 `venue+instrument+interval` 启用流的滚动 30 天分别计算，只统计已闭合且可交易的 UTC 时间槽；每条流不低于 99.99%，唯一键重复为零。
- 行情恢复从 Collector 确认连接/心跳失效计时，到首条规范化事件成功落库结束；本地恢复目标不超过 30 秒，交易所官方故障单独分类。
- 相同策略、数据集、参数和镜像必须产生相同规范化订单、成交和权威账本。
- A5 黄金案例中的订单状态、成交、费用、仓位和复式分录逐项一致；任一可复现差异触发 NautilusTrader 定向验证。
- 重试不得产生重复订单；急停后不得新增敞口；重启后账户、订单、成交、仓位和余额完成自动对账。
- R2 需要模拟盘至少 30 天、100 笔完成订单和无未解释账务差异；R3 还需要现货稳定 30 天以及永续模拟/Testnet 30 天、100 笔。

领域指标在对应能力实现前只是目标，禁止用空测试或固定成功结果伪造通过。

## 证据

仓库只保存稳定的证据模板和测量口径。每个 GitHub 跟踪 Issue 链接适用的 CI run、Manifest/哈希、质量报告、恢复或急停演练和用户审批；动态“是否通过”不回写仓库。
