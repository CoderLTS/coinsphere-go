# CoinSphere 路线图

## 产品方向

CoinSphere 从通用后台与工作流系统演进为个人币圈量化平台，固定路径为：

`行情采集 -> 数据治理 -> K线研究 -> 新闻因子 -> 策略开发 -> 双回测 -> 内置模拟盘 -> 小额现货 -> USDT永续`

首轮支持 Binance、OKX、现货、USDT 永续逐仓双向持仓。首轮不支持逐笔成交、完整盘口、跨交易所套利、多标的组合、币本位、全仓、高频交易、高级算法单或 AI 自主交易。

完整范围、PR 顺序、阶段门禁和验收标准见 [全流程实施计划](./implementation-plan.md)。

## 执行方式

- A1-5 已完成集中验证和一次只读复审，本轮不扩展其他功能。
- A1 剩余目标合并为三个纵向 PR：`codex/a1-postgres-baseline`、`codex/a1-security-baseline`、`codex/a1-observability`。三个 PR 可在独立 worktree 中并行实现，按 PostgreSQL、安全、观测顺序 rebase 和手工合并。
- A2 以后每个阶段先冻结最小公共契约，再并行开发 Binance、OKX、公共能力/UI 等文件所有权独立的纵向切片；同一波次只进行一次集中验证和汇总复审。
- 所有代码实现和修改使用当前主模型；`gpt-5.6-terra`、思考等级 `max` 只承担资料检索、仓库探索、代码阅读、文件定位和信息整理。没有真实并行收益时不创建子 Agent。

## 阶段门禁

- 研究版本以可复现的 vectorbt 与 NautilusTrader 双回测为退出条件。
- 模拟盘连续运行 30 天且至少完成 100 个订单、无未解释账务差异，才能申请现货放行。
- 小额现货连续稳定 30 天后才能申请永续放行。
- 每个开发波次只提交一次汇总报告；研究版本、模拟盘、现货和永续的阶段晋级仍由用户审查并手工确认。
