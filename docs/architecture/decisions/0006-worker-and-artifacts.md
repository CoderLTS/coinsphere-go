# ADR-0006：Rootless Worker 与不可变产物

- 状态：已被 ADR-0009 替代
- 日期：2026-08-04
- 替代日期：2026-08-05

## 背景

当前 Python Worker 直接在进程内执行伪任务。真实策略和回测包含用户 Python 代码，必须限制网络、资源、凭据和主机权限，同时保持现有 PostgreSQL 租约与取消协议。

## 决策

- 专用 Launcher 运行独立 Rootless Docker daemon，私有 Socket 只允许 Launcher 访问；业务角色和任务容器都不获得 Docker Socket。
- Launcher 直接轮询 PostgreSQL 任务队列，复用租约、心跳、取消和 fencing，不新增 HTTP/gRPC 执行服务。
- 每个任务启动一个一次性容器：无网络、无 DSN、无密钥、只读输入、独立可写产物目录、固定 CPU/内存/时间/空间限制，结束后销毁。
- 镜像必须来自服务端固定 digest 白名单。A4 首期只提供 vectorbt 镜像；任务运行时禁止下载或安装依赖。
- 任务类型和参数 Schema 版本化；镜像 digest、输入资源 ID、结果 Manifest 和租约归属落库。Launcher 启动时按任务与租约标签清理孤儿容器。
- 产物先写临时文件，完成后校验哈希并原子登记 Manifest；失败保留源数据和失败记录并重试，进入 `immutable` 前禁止清理源数据。
- 已发布策略、引用数据集和交易/审批证据禁止自动删除。失败临时文件保留 7 天，未引用普通回测报告保留 90 天，GC 只删除已确认无引用的内容。
- A4-A6 可只使用本机不可变卷；进入 R2 前必须为关键策略包、Manifest、审批、账务和对账证据建立加密独立副本并完成恢复演练。

## 结果

- 用户策略不接触数据库、交易凭据或宿主 Root Docker，崩溃和取消可沿用现有任务协议恢复。
- 首期不支持任意依赖、自定义镜像、对象存储或多机执行；出现真实需求后再增加。
